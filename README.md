# Radicle Academy

Welcome to **Radicle Academy**, and welcome to Radicle.

If you are reading this, you have just joined [Radicle](https://www.radicle.it) as a **Radicler**. This repository is your starting point: it defines the training path every new Radicler is expected to follow, focused on the Oracle stack we build on every day.

## Step 1: Register on Oracle MyLearn

Before anything else, create an account on **[Oracle MyLearn](https://mylearn.oracle.com)** using your **`@radicle.it` email address**. All training courses live there, and using your work email keeps your progress, badges, and exam vouchers tied to Radicle.

## Step 2: Follow your level path

The training path is organized into **levels**. Each level is described in its own page under [`levels/`](./levels):

- **[Level 1: Foundations](./levels/level-1.md)**. The mandatory foundation for every Radicler in their first year: SQL, PL/SQL, and APEX certifications, with relative deadlines.
- **Level 2: Intermediate / Expert**. _To be defined_. Deeper database administration, advanced APEX, OCI, and BI/ETL topics. The page will appear here once finalized.

Start with Level 1 and work through it in order.
